# Morrow Studio — сайт digital-студии

Представляет вымышленную студию через адаптивный одностраничный сайт.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Адаптивная сетка, CSS-композиции кейсов и фильтр проектов.
- Состояния наведения, плавная навигация и клиентская форма.

## Стек
HTML, CSS, JavaScript.

## Запуск и проверка
Python 3.12.14 для локального HTTP-сервера; сборка не нужна.

```bash
node --check script.js
python tests/check_assets.py
python -m http.server 8080
```

## Технические решения
- Сайт работает без сборки и UI-фреймворка.
- Форма явно сообщает, что демонстрационные данные не отправлены.

## Границы готовности
- Morrow, её команда, стаж, кейсы и контакты — вымышленный контент для портфолио.
- Бэкенд формы и отправка писем отсутствуют. Карточки открывают описание вымышленных кейсов внутри страницы.

## Проверка документации и обновлений

`python .github/scripts/check_docs.py` проверяет ссылки на файлы и изображения в Markdown, регистр имён и случайные локальные ссылки. Примеры команд внутри блоков кода не проверяются как ссылки. `--external` дополнительно проверяет публичные HTTP-ссылки: 404/410 считаются ошибками; авторизация, сетевые сбои и ограничения сервиса отмечаются как непроверенные. HTTP-проверка запускается еженедельно и вручную; локальные ссылки — при каждом push/PR. Фрагменты внутри страниц не проверяются.

Dependabot еженедельно предлагает сгруппированные обновления зависимостей и GitHub Actions. Автоматического слияния нет; обновления проходят CI. [История версии](CHANGELOG.md).
