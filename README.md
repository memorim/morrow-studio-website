# Morrow Studio - сайт цифровой студии

Адаптивный сайт студии: проекты, фильтры, услуги, навигация и контактная форма.

[Открыть сайт на Render](https://memorim-morrow.onrender.com/) · [GitHub Pages](https://memorim.github.io/morrow-studio-website/)

## Устройство проекта

HTML, CSS и JavaScript без сборщика. Express обслуживает сайт и принимает обращения. PostgreSQL хранит заявки. Выбранную категорию проектов можно открыть по ссылке, обновить и вернуться к ней кнопкой «Назад».

## Локальный запуск и проверки

Node.js 24.18 и PostgreSQL. Укажите строку подключения в переменной окружения `DATABASE_URL`.

```bash
node --check script.js
python tests/check_assets.py
python .github/scripts/check_docs.py
pnpm install --frozen-lockfile
node server.js
```

Откройте `http://localhost:4832`. При запуске сервер применяет [миграцию](migrations/001_inquiries.sql). Карточки открывают краткое описание в диалоге.

Для браузерных проверок нужны Node.js 24.18.0 и pnpm 11.7.0:

```bash
pnpm install --frozen-lockfile
pnpm exec playwright install --with-deps --only-shell chromium
pnpm test:e2e
```

CI запускает сайт с отдельной тестовой PostgreSQL. На компьютере, планшете и телефоне проверяются отправка заявки, повтор запроса, валидация, фильтры и навигация.

## Обработка заявок

`POST /api/inquiries` сохраняет имя, рабочую почту и описание проекта. После подтверждения записи форма показывает результат. При ошибке текст остаётся в полях, повтор с тем же ключом сохраняет одну заявку.

Владелец просматривает заявки в закрытой таблице `morrow_inquiries` своего проекта PostgreSQL. Уведомления по почте не настроены.

## Состояние скриншотов и ограничений

Скриншоты ПК и телефона (`docs/desktop.png` и `docs/mobile.png`) соответствуют опубликованной версии сайта. При изменении цветовой гаммы, вёрстки или другого видимого элемента обновляйте оба файла после загрузки шрифтов и изображений; не включайте токены и персональные данные.

Бесплатное размещение Render/GitHub Pages используется для проверки. Заявки сохраняются в PostgreSQL, а почтовые уведомления пока не настроены; бесплатный вариант уведомлений описан в [FREE_NOTIFICATIONS.md](docs/FREE_NOTIFICATIONS.md). Перед рабочим использованием нужно отдельно проверить постоянную базу и доставку уведомлений.

## Бесплатная доставка уведомлений

Очередь заявок можно обрабатывать без платного фонового worker через `.github/workflows/free-notifications.yml`. Добавьте в настройках репозитория Secrets `MORROW_DATABASE_URL` и `MORROW_NTFY_TOPIC`; workflow запускается каждые пять минут или вручную и отправляет уведомления через бесплатный ntfy. Без этих секретов доставка остаётся отключённой.
